# Open `weathergpt.html`

The whole frontend in one file. Double-click it — no install, no server, no key.

It asks where your farm is first and that cannot be skipped: every figure in
the product is computed for one place and there is no honest default. If GPS is
denied and there is no network, the bundled list of 34 districts still works.

Running on sample data, and it says so in its own footer.

Crop Doctor and Soil Check will tell you no model is connected. That is
correct — they never invent a diagnosis, and with no `HF_TOKEN` there is
nothing to analyse the photo with.

To run the real thing — live forecasts, real NDMA warnings, the risk engines —
see **`../RUN.md`**. It is two commands.
